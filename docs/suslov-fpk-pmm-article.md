# Стационарные флуктуации угловой скорости в задаче Суслова при I₁₃ > 0: усреднение и поправки Чепмена–Энскога

**С. А. Matyukhin**  
Independent Researcher  
ORCID: 0009-0005-1704-8371

---

## Аннотация

Рассмотрена задача Суслова с произведением инерции I₁₃ = D > 0 при вязком трении Φ = φ₀I и аддитивном гауссовом шуме в редуцированных уравнениях для ω. В отличие от случая главной оси связи [9], больцмановская плотность на плоскости связи при D > 0 не стационарна. Точно найдены одномерный закон кинетической энергии (диффузия Феллера), маргинальный закон Рэлея для r = |ω| и моментное тождество, связывающее E[ω₂] с E[ω₁²].

Ведущее двумерное приближение стационарной плотности получено методом усреднения по быстрому углу θ (Хасминский): p⁽⁰⁾ = p_R(r)·p(θ|r) с точным Рэлеем по r и законом фон Мизеса по θ; при D = 0 оно совпадает с гауссовым стационаром. Систематические поправки порядков ε² и ε⁴ выписаны разложением Чепмена–Энскога; поправка ε² устраняет главный член невязки больцмановского анзаца (D/A)ω₂. Линеаризация p⁽⁰⁾ при λ(r) ≫ 1 даёт профиль f* (условный гауссов слой по ω₁ и Рэлей по ω₂ > 0). Сходимость плотностей в строгом смысле не утверждается; приведены моменты приближений, сравнение с нормальной аппроксимацией и численная иллюстрация.

**Ключевые слова:** задача Суслова, неголономная связь, уравнение Фоккера–Планка, стационарные флуктуации, усреднение, слабый шум.

## 1. Введение

Задача Суслова [1, 2] — образец линейной неголономной связи. Общие основы неголономной механики изложены в [3]. В настоящей работе поле тяжести не рассматривается: свободное тело с неподвижной точкой и связью ω₃ = 0. Уравнения для ориентации γ не входят в статистику угловой скорости, так как правые части для ω от γ не зависят.

При I₁₃ ≠ 0 ось связи не главная: детерминированная система не допускает гладкой инвариантной меры [5, 6]. В [9] при I₁₁ = I₂₂ и Φ = φ₀I, ν = ν₀I получен точный гауссов стационар на плоскости связи. Настоящая работа разбирает тот же тип трения и шума при **I₁₃ = D > 0**. Гауссов анзац

f_B(ω₁, ω₂) ∝ exp(−α(ω₁² + ω₂²)), α = Aφ₀/ν₀, (1.1)

даёт невязку уравнения Фоккера–Планка (ФПК) пропорциональную ω₂ — стохастический аналог отсутствия гладкой инвариантной меры.

**Основные результаты.**

1. Кинетическая энергия T на связи — точная одномерная диффузия Феллера; D из закона T выпадает. Маргиналь r = |ω| — закон Рэлея (3.3).

2. Точное моментное тождество E[ω₂] = (D/(Aφ₀))E[ω₁²] (3.4); средний дрейф вокруг оси Oy возникает только при связи ω₃ = 0 **и** D > 0.

3. **Ведущее приближение p⁽⁰⁾** (усреднение по θ): точный Рэлей × фон Мизеса (4.3)–(4.4); при D = 0 — гаусс (1.1).

4. **Поправки Чепмена–Энскога:** p₁ = −(D/A)p₀/r (O(ε²)), p₂ с членом ∝ cos θ (O(ε⁴)); единая формула (5.6). Поправка p₁ согласована с невязкой (3.5).

5. Предел λ(r) ≫ 1 даёт линеаризованный профиль f* (4.9). Численная проверка при ε ≈ 0,14: p⁽⁰⁾ ближе к Монте-Карло, чем f*.

## 2. Модель

### 2.1. Тензор инерции и связь

Тело с неподвижной точкой O, ось Oz — ось связи. Принимаем динамическую симметрию на плоскости, ортогональной Oz: I₁₁ = I₂₂ = A, I₁₂ = 0; поворотом Ox, Oy вокруг Oz достигается I₂₃ = 0, I₁₃ = D > 0:

```
      | A  0  D |
I =   | 0  A  0 |,   A > 0,  C > 0,  AC > D².     (2.1)
      | D  0  C |
```

Связь Суслова: **ω₃ = 0.** На связи T = (A/2)(ω₁² + ω₂²); I₃₃ = C в редуцированную динамику не входит.

### 2.2. Диссипация, шум и уравнения

Φ = φ₀I, ν₀ > 0, изотропное трение и аддитивный шум в редуцированных уравнениях (приложение A):

```
dω₁ = (−(D/A)ω₁ω₂ − φ₀ω₁) dt + σ dW₁,
dω₂ = ( (D/A)ω₁² − φ₀ω₂) dt + σ dW₂,              (2.5)
```

σ = √(ν₀/A). Стационарное ФПК: L*f = 0,

```
a₁ = −(D/A)ω₁ω₂ − φ₀ω₁,   a₂ = (D/A)ω₁² − φ₀ω₂,
L*f = −∂_{ω₁}(a₁f) − ∂_{ω₂}(a₂f) + (σ²/2)Δf.     (2.6)
```

При D = 0 — изотропный процесс Орнштейна–Уленбека, стационар (1.1).

**Режим слабого шума и трения:**

φ₀ = ε²φ̂, ν₀ = ε²ν̂, σ = ε√(ν̂/A), ε ∈ (0, 1]. (2.7)

Отношение φ₀/ν₀ (масштаб E[T]) от ε не зависит. Обозначим **κ = D/A** (константа при ε → 0).

### 2.3. Полярные координаты

ω₁ = r sin θ, ω₂ = r cos θ, r ≥ 0.

**Лемма 1.** Процесс (2.5) эквивалентен

```
dr = (−φ₀r + σ²/(2r)) dt + σ dW_r,
dθ = −(D/A) r sin θ dt + (σ/r) dW_θ,               (2.8)
```

где W_r, W_θ независимы. Процесс r (и T) **марковские и не содержат D**: гироскопические члены сокращаются в d(r²).

При φ₀ = ν₀ = 0 поле на окружности r = const имеет устойчивую точку θ = 0 (ω₂ = +r) и неустойчивую θ = π.

## 3. Точные результаты

### 3.1. Энергия

**Утверждение 3.1.** T = A r²/2 удовлетворяет

```
dT = (−2φ₀T + ν₀) dt + √(2ν₀T) dW.                 (3.1)
```

Процесс (3.1) — диффузия Феллера [12]; индекс границы T = 0 равен 2 (входная граница). **D в (3.1) отсутствует.**

**Утверждение 3.2.** Стационарная плотность T на (0, ∞):

```
f_T(T) = (2φ₀/ν₀) exp(−(2φ₀/ν₀)T),   E[T] = ν₀/(2φ₀).   (3.2)
```

Эквивалентно, r имеет закон **Рэлея**

```
p_r(r) = 2α r exp(−α r²),   α = Aφ₀/ν₀,   r > 0.     (3.3)
```

### 3.2. Моментное тождество и невязка больцмана

**Утверждение 3.3.** Для стационарной μ процесса (2.5):

```
E_μ[ω₂] = (D/(Aφ₀)) E_μ[ω₁²].                        (3.4)
```

**Утверждение 3.4.** Для f_B = c exp(−α(ω₁² + ω₂²)):

```
(L*f_B)/f_B = (D/A) ω₂.                              (3.5)
```

Гаусс (1.1) **не** стационарен при D > 0. Невязка (3.5) — источник поправки p₁ (§5).

### 3.3. Существование стационара

**Утверждение 3.5.** При φ₀, ν₀ > 0 существует единственная стационарная плотность f ∈ C^∞(ℝ²), f > 0; все моменты конечны. E[T] = ν̂/(2φ̂) не зависит от ε в режиме (2.7). Существование следует из теоремы Хасминского [13] (Lyapunov-функция V = 1 + T).

## 4. Ведущее приближение: усреднение по быстрому углу

### 4.1. Разделение масштабов

Из (2.8) при режиме (2.7):

| Переменная | Время релаксации | Роль |
|-----------|------------------|------|
| θ | O(1) | быстрая (связь κ = D/A) |
| r | O(1/ε²) | медленная (трение, шум) |

Лемма 1: **r и T не «чувствуют» D**; гироскопия — только в уравнении для θ.

### 4.2. Утверждение об усреднении

По методу усреднения быстро осциллирующих систем [13] (см. также [14]) стационарная плотность f^ε процесса (2.5) на **ведущем порядке** факторизуется:

```
f^ε(r, θ) = p⁽⁰⁾(r, θ) + O(ε²),   r > 0,              (4.1)
```

```
p⁽⁰⁾(r, θ) = p_r(r) · p(θ | r) / r
            = (α/π) exp(−α r²) · exp(λ(r) cos θ) / I₀(λ(r)).   (4.2)
```

```
p_r(r) = 2α r exp(−α r²)          — точный (3.3),
p(θ | r) = exp(λ(r) cos θ) / (2π I₀(λ(r))),
λ(r) = 2D r³/(A σ²) = 2D r³/ν₀.                        (4.3)
```

I₀ — модифицированная функция Бесселя, I₀(0) = 1. При D = 0: λ ≡ 0, p(θ|r) = 1/(2π), p⁽⁰⁾ = (α/π)exp(−α(ω₁² + ω₂²)) — гаусс (1.1).

**В декартовых координатах** (s = ω₁² + ω₂²):

```
p⁽⁰⁾(ω₁, ω₂) = (α/π) exp(−α s) · exp(2D ω₂ s/ν₀) / I₀(2D s^{3/2}/ν₀),   s > 0.   (4.4)
```

**Проверка применимости** (вместо полного доказательства): (i) θ эргодичен на окружности при σ > 0; (ii) confining-распределение по r из (3.3); (iii) E[T] = ν₀/(2φ₀) совпадает с (3.2).

**Замечание 1.** Невязка L*p⁽⁰⁾ при D > 0 связана с зависимостью λ(r) от r (члены λ′(r) при подстановке в (2.6)). Это **остаток порядка O(ε²)**, не устраняемый на уровне p⁽⁰⁾; поправка p₁ (§5) снимает главный член, пропорциональный ω₂ в (3.5).

### 4.3. Предел λ → 0 и режим (2.7)

При r = O(1) и (2.7): λ(r) = O(ε⁻²) ≫ 1. Масса p(θ|r) сосредоточена у θ = 0 (устойчивая полуось ω₂ > 0); область ω₂ < 0 подавлена как O(e^{−2λ}).

## 5. Поправки Чепмена–Энскога

Разложение стационарного adjoint-оператора L* = L₀* + ε²L₁* (быстрый угол / медленное трение + диффузия) даёт формальную иерархию

```
f^ε = p⁽⁰⁾ + ε² p₁ + ε⁴ p₂ + O(ε⁶).                  (5.1)
```

**Статус:** явные p₁, p₂ согласованы с уравнением на порядках ε², ε⁴; **сходимость ряда не утверждается**.

### 5.1. Поправка O(ε²): p₁

Источник на уровне гаусса p₀ = (α/π)exp(−α r²):

```
G(p₀) = ∇·(b_D p₀) = κ ω₂ p₀ = (D/A) ω₂ p₀.          (5.2)
```

(совпадает с (3.5)). Частное решение:

```
p₁(ω₁, ω₂) = −κ p₀/r = −(D/A) (α/π) exp(−α(ω₁² + ω₂²)) / √(ω₁² + ω₂²).   (5.3)
```

p₁ **радиально симметричен** (не зависит от θ). Член p₁ ~ 1/r сингулярен при r → 0 — особенность формального ряда; маргиналь p_r(r) из (3.3) регулярна.

### 5.2. Поправка O(ε⁴): p₂

Главные члены:

```
p₂(r, θ) = p₀(r) · [ κ²/(2r²) + κ² cos θ/(2φ̂) ],     (5.4)
```

φ̂ = φ₀/ε² = const в режиме (2.7). Угловая зависимость ∝ cos θ = ω₂/r впервые входит в p₂.

### 5.3. Единая формула (усреднение + CE)

```
f_approx(ω₁, ω₂) = p⁽⁰⁾(ω₁, ω₂)
                   − ε² (D/A) p₀/r
                   + ε⁴ p₀ [ (D/A)²/(2r²) + (D/A)² cos θ/(2φ̂) ].   (5.5)
```

С нормировкой (опционально): f^ε ≈ f_approx / Z(ε), Z(ε) = 1 − ε²κ√(απ) + O(ε⁴).

**Связь с (3.5):** поправка −ε²(D/A)p₀/r компенсирует главный член невязки больцмановского анзаца; p⁽⁰⁾ уже содержит угловую структуру через фон Мизеса.

## 6. Линеаризация: профиль f*

При λ(r) ≫ 1:

```
p(θ | r) ≈ √(λ/(2π)) exp(−λ θ²/2),   Var(θ|r) ≈ 1/λ,
Var(ω₁ | r) ≈ ν₀/(2D r).                              (6.1)
```

Замена r ≈ ω₂, ω₂ > 0 в зоне линеаризации:

```
ω₁ | ω₂ ∼ N(0, ν₀/(2D ω₂)),   ω₂ > 0.                 (6.2)
```

Маргиналь по ω₂ — Рэлей ρ₀(ω₂) = 2α ω₂ exp(−α ω₂²), ω₂ > 0. **Линеаризованный профиль:**

```
f*(ω₁, ω₂) = √(D ω₂/(π ν₀)) exp(−(D ω₂/ν₀) ω₁²) · 2α ω₂ exp(−α ω₂²),   ω₂ > 0.   (6.3)
```

f* — линеаризация p⁽⁰⁾ при λ ≫ 1; **не** отдельный анзац, а предел узкого углового слоя. Тождество (3.4) на f* выполняется **точно**. f* завышает Var(ω₁) и занижает Var(θ) относительно p⁽⁰⁾ и МК (§8).

При D = 0 профиль f* не определён (слой (6.2) содержит 1/D).

## 7. Моменты и механический смысл

### 7.1. Моменты p⁽⁰⁾

По построению: E[p⁽⁰⁾][T] = ν₀/(2φ₀), E[p⁽⁰⁾][ω₁] = 0. Остальные моменты — через E[g] = E_r[E_θ[g | r]] с (4.3); например

```
E[p⁽⁰⁾][ω₂] = ∫₀^∞ r [I₁(λ)/I₀(λ)] p_r(r) dr.
```

### 7.2. Моменты f*

**Утверждение 7.1.** По (6.3):

```
E[ω₁] = 0,   E[ω₂] = (√π/(2√α)) = (1/2)√(π ν₀/(Aφ₀)),
E[ω₁²] = (√(π A ν₀ φ₀))/(2D),   E[ω₂²] = ν₀/(Aφ₀),
Var(ω₂) = (4 − π)ν₀/(4Aφ₀),   Cov(ω₁, ω₂) = 0.
```

В режиме (2.7): E[ω₂] = O(1), Var(ω₁) = O(ε²).

### 7.3. Механический смысл E[ω₂] > 0

Сдвиг среднего вращения к полуоси ω₂ > 0 возникает только при **одновременном** наличии связи ω₃ = 0 и D > 0: связь редуцирует динамику на плоскость; D ломает симметрию ω₂ ↔ −ω₂ через гироскопические члены в (2.5). Без связи или при D = 0: E[ω₂] = 0 [9].

### 7.4. Нормальная аппроксимация (кратко)

Метод [10, 11] даёт m₂ = (D/(Aφ₀))K₁₁; качественно m₂ > 0, K₁₁ = O(ε²). Количественно f* даёт закон Рэлея по ω₂, а не гаусс; NA — иллюстрация знаков, не приближение f*.

**Таблица 1.** Моменты f* в режиме (2.7)

| величина | асимптотика | смысл |
|----------|-------------|-------|
| E[ω₁] | 0 | симметрия слоя |
| E[ω₂] | (1/2)√(πν₀/(Aφ₀)) | сдвиг к устойчивой полуоси |
| Var(ω₁) | O(ε²) | толщина слоя |
| Var(ω₂) | O(1) | разброс энергии |
| Cov(ω₁, ω₂) | 0 | оси эллипса координатные |

Интегрирование (2.5) схемой Эйлера–Маруяма: A = 1, D = 0,5, φ₀ = ν₀, dt = 5·10⁻⁴, 48 траекторий, длина 800, отжиг 120. При φ₀ = ν₀ = 0,02: α = 1, E[T] = 1/2, ε ≈ 0,14.

| E[ω₂] | 0,856 | 0,886 | 0,83 ± 0,02 |
| Var(ω₁) | 0,018 | 0,035 | 0,033 ± 0,001 |

## 9. Заключение

Для задачи Суслова с I₁₃ = D > 0 установлено:

1. **Точные** одномерные законы T и r (§3); **точное** тождество (3.4); гаусс (1.1) не стационарен — невязка (3.5).

2. **Ведущее 2D-приближение p⁽⁰⁾** — усреднение по быстрому θ (§4): Рэлей × фон Мизеса; при D = 0 — гаусс.

3. **Поправки CE** p₁, p₂ (§5) систематически уточняют плотность; p₁ связан с (3.5).

4. **f*** — линеаризация p⁽⁰⁾ при слабом шуме; численно p⁽⁰⁾ предпочтительнее f* при ε ≈ 0,14.

Сходимость f^ε → p⁽⁰⁾ + ε²p₁ + … в строгом смысле **не утверждается**; для p⁽⁰⁾ достаточно ссылки на [13] и проверки §4.2.

**Открытые вопросы:** оценка остатка f − p⁽⁰⁾ − ε²p₁; внутренний слой r ~ O(ε); обобщение на I₁₁ ≠ I₂₂.

## Приложение A. Вывод редуцированных уравнений

I ω̇ + ω × (Iω) = M + Λe_z + ξ. При ω₃ = 0, (2.1):

```
A ω̇₁ = −Aφ₀ω₁ − Dω₁ω₂ + ξ₁,
A ω̇₂ = −Aφ₀ω₂ + Dω₂² + ξ₂.
```

Λ и ξ₃ не входят в первые две компоненты (утверждение A.1). Для σ = √(ν₀/A) нужно E[ξ_i ξ_j] = Aν₀ δ_{ij} δ(t−s), i,j = 1,2 — согласование с (3.1).
