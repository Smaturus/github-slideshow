# Стационарное УФПК для системы (2.5): асимптотика при малом ε

Режим **слабого шума и трения** (уравнения 2.5–2.7). Стационарное решение, разложение по ε², уравнение для первой поправки.

---

## 1. Обозначения

| Символ | Определение |
|--------|-------------|
| κ | D · A⁻¹ (связь из уравнений Эйлера) |
| α | φ̂ (нормированное трение) |
| ν | ν̂ (нормированная интенсивность шума) |
| σ₀ | √(ν · A⁻¹) |
| σ | ε · σ₀ |
| φ₀ | ε² · α |
| β | α · A · ν⁻¹ |

Малый параметр: **ε ∈ (0, 1]**.

**Полярные координаты:** ω₁ = r sin θ, ω₂ = r cos θ, r ≥ 0.

Отношение φ₀ · ν₀⁻¹ (масштаб средней энергии) **не зависит от ε**.

---

## 2. Система (2.5) в нормированных параметрах

```
dω₁ = (−κ·ω₁·ω₂ − ε²·α·ω₁) dt + ε·σ₀ dW₁
dω₂ = ( κ·ω₁²   − ε²·α·ω₂) dt + ε·σ₀ dW₂
```

- Шум **аддитивный** → исчисления Ито и Строноновича совпадают.
- При D = 0 (κ = 0): изотропный процесс Орнштейна–Уленбека.

---

## 3. Разложение стационарной плотности

```
p^ε(ω₁, ω₂) = (1 / Z(ε)) · [ p₀ + ε² · p₁ + ε⁴ · p₂ + O(ε⁶) ]
```

Члены с нечётными степенями ε отсутствуют (трение и диффузия входят как ε²).

**Z(ε) = 1 − ε² · κ · √(βπ) + O(ε⁴)** — нормировочная константа.

---

## 4. Ведущий член p₀ (гаусс при D = 0)

При κ = 0 стационарное распределение **точное** и **не зависит от ε**:

```
p₀(ω₁, ω₂) = (β / π) · exp( −β · (ω₁² + ω₂²) )
```

где **β = α·A / ν**.

Маргинальная плотность по ω₁:

```
ρ₀(ω₁) = √(β / π) · exp( −β · ω₁² )
```

Дисперсия: **E[ω₁²] = ν / (2·α·A)**.  
Средняя энергия: **E[E] = ν / (4·α·A)**, E = ½(ω₁² + ω₂²).

---

## 5. Стационарное УФПК

Дрейф:

```
b₁ = −κ·ω₁·ω₂ − ε²·α·ω₁
b₂ =  κ·ω₁²   − ε²·α·ω₂
```

Стационарное уравнение (нулевой ток):

```
∂/∂ω₁ (b₁ · p) + ∂/∂ω₂ (b₂ · p) = (ε² · σ₀² / 2) · Δp
```

Векторно: **∇·(b · p) = (ε² · σ₀² / 2) · Δp**.

Разделение дрейфа:

```
b = b_D + ε² · b_f

b_D = ( −κ·ω₁·ω₂ ,  κ·ω₁² )        — нелинейная связь
b_f = ( −α·ω₁     , −α·ω₂ )        — трение (Rayleigh)
```

---

## 6. Уравнение для первой поправки p₁ (порядок ε²)

Полное стационарное уравнение на порядке ε² (при **κ = O(1)**):

```
∇·(b_D · p₁) + ∇·(b_f · p₁) − (σ₀² / 2) · Δp₁ = κ · ω₂ · p₀
```

Эквивалентная форма через **p₁ = Q · p₀** (так как **b_D · ∇p₀ = 0**):

```
∇·(b_D · Q) − (σ₀² / 2) · ΔQ = κ · ω₂
```

---

## 7. Явное выражение для p₁

Обозначим **r = √(ω₁² + ω₂²)**. При **r > 0** частное решение:

```
p₁(ω₁, ω₂) = −κ · p₀(ω₁, ω₂) / r
```

**В декартовых координатах:**

```
p₁(ω₁, ω₂) = − κ · (β / π) · exp( −β · (ω₁² + ω₂²) ) / √(ω₁² + ω₂²)
```

**В полярных координатах:**

```
p₁(r, θ) = − κ · (β / π) · exp( −β · r² ) / r
```

Поправка **p₁ не зависит от угла θ**, только от радиуса **r**.

### Проверка

Подстановка **Q = −κ / r** в уравнение для **Q**:

- **∇·(b_D · Q) = κ · ω₂**
- **Δ(1/r) = 0** при **r > 0** в двумерном случае

### Нормировка полной плотности

Интеграл **∬ p₁ dω₁ dω₂ = −κ · √(βπ) ≠ 0**. Нормированная плотность:

```
p^ε = (1 / Z(ε)) · ( p₀ + ε² · p₁ + … )
```

```
Z(ε) = 1 − ε² · κ · √(βπ) + O(ε⁴)
```

### Замечание

Член **p₁ ~ −κ / r** сингулярен при **r → 0** — особенность формального ряда. Формула описывает основную массу при **r = O(1)**.

---

## 8. Полная плотность p в виде ряда (явно)

Общий вид (при **κ = O(1)**, **r > 0**):

```
p^ε = (1 / Z(ε)) · [ p₀ + ε² · p₁ + ε⁴ · p₂ + O(ε⁶) ]
```

### Декартовы координаты (ω₁, ω₂)

```
p^ε(ω₁, ω₂) = (1 / Z(ε)) · {
    (β/π) · exp( −β·(ω₁² + ω₂²) )
  − ε² · κ · (β/π) · exp( −β·(ω₁² + ω₂²) ) / √(ω₁² + ω₂²)
  + ε⁴ · p₂(ω₁, ω₂)
  + O(ε⁶)
}
```

**Компактная форма** (вынесен общий множитель):

```
p^ε(ω₁, ω₂) = (β / πZ(ε)) · exp( −β·(ω₁² + ω₂²) ) · [ 1 − ε²·κ / √(ω₁² + ω₂²) + ε⁴·Q₂(ω₁, ω₂) + O(ε⁶) ]
```

где **Q₂ = p₂ / p₀**.

### Полярные координаты (r, θ)

```
ω₁ = r · sin θ ,   ω₂ = r · cos θ ,   r = √(ω₁² + ω₂²) ,   r ≥ 0
```

```
p^ε(r, θ) = (1 / Z(ε)) · {
    (β/π) · exp( −β·r² )
  − ε² · κ · (β/π) · exp( −β·r² ) / r
  + ε⁴ · p₂(r, θ)
  + O(ε⁶)
}
```

**Компактная форма:**

```
p^ε(r, θ) = (β / πZ(ε)) · exp( −β·r² ) · [ 1 − ε²·κ / r + ε⁴·Q₂(r, θ) + O(ε⁶) ]
```

**p₀ и p₁ не зависят от θ**; угловая зависимость появляется в **p₂**.

### Явное выражение для p₂ (порядок ε⁴)

Уравнение для **p₂**:

```
∇·(b_D · p₂) + ∇·(b_f · p₂) − (σ₀² / 2) · Δp₂ = G(ω₁, ω₂) · p₀
```

```
G(ω₁, ω₂) = κ·α / r + κ²·ω₂ + κ·ν / (2·A·r³)     ,   r = √(ω₁² + ω₂²)
```

```
G(r, θ) = κ·α / r + κ²·r·cos(θ) + κ·ν / (2·A·r³)     ,   ω₂ = r·cos θ
```

**Явное решение (главные члены порядка ε⁴):**

```
p₂(ω₁, ω₂) = p₀(ω₁, ω₂) · [ κ² / (2·r²) + κ²·ω₂ / (2·α·r) ]
```

**В декартовых координатах:**

```
p₂(ω₁, ω₂) = (β / π) · exp( −β·(ω₁² + ω₂²) ) · [
    κ² / ( 2·(ω₁² + ω₂²) )
  + κ²·ω₂ / ( 2·α·(ω₁² + ω₂²)^(3/2) )
]
```

**В полярных координатах** (ω₁ = r sin θ, ω₂ = r cos θ):

```
p₂(r, θ) = (β / π) · exp( −β·r² ) · [ κ² / (2·r²) + κ²·cos(θ) / (2·α) ]
```

**Множитель Q₂ = p₂ / p₀:**

```
Q₂(r, θ) = κ² / (2·r²) + κ²·cos(θ) / (2·α)
```

---

### Полная плотность p^ε (подстановка p₀, p₁, p₂)

**Декартовы координаты:**

```
p^ε(ω₁, ω₂) = (1 / Z(ε)) · (β / π) · exp( −β·(ω₁² + ω₂²) ) · {
    1
  − ε² · κ / r
  + ε⁴ · [ κ² / (2·r²) + κ²·ω₂ / (2·α·r) ]
  + O(ε⁶)
}
```

```
r = √(ω₁² + ω₂²)
```

**Полярные координаты** (ω₁ = r sin θ, ω₂ = r cos θ):

```
p^ε(r, θ) = (1 / Z(ε)) · (β / π) · exp( −β·r² ) · {
    1
  − ε² · κ / r
  + ε⁴ · [ κ² / (2·r²) + κ²·cos(θ) / (2·α) ]
  + O(ε⁶)
}
```

**Развёрнутая форма (полярная):**

```
p^ε(r, θ) = (1 / Z(ε)) · {
    (β/π) · exp( −β·r² )
  − ε² · κ · (β/π) · exp( −β·r² ) / r
  + ε⁴ · (β/π) · exp( −β·r² ) · [ κ²/(2·r²) + κ²·cos(θ)/(2·α) ]
  + O(ε⁶)
}
```

### Нормировка

```
Z(ε) = 1 − ε² · κ · √(βπ) + O(ε⁴)
```

---

## 9. Маргинальная плотность: связное уравнение

```
p₁^marg(ω₁) = ∫ p₁(ω₁, ω₂) dω₂     (интеграл по всей оси ω₂)
```

Определим момент:

```
m(ω₁) = ∫ ω₂ · p₁(ω₁, ω₂) dω₂
```

После интегрирования уравнения для p₁ по ω₂:

```
κ·ω₁ · m(ω₁) = 2·α · ( β·ω₁² − ½ ) · ρ₀(ω₁)
```

Отсюда явно:

```
m(ω₁) = (2·α / (κ·ω₁)) · ( β·ω₁² − ½ ) · ρ₀(ω₁)     при ω₁ ≠ 0
```

Полная p₁^marg(ω₁) — чётная функция; восстанавливается из 2D-уравнения, а не только из m(ω₁).

## 11. Какой метод когда (стационарный случай)

| Ситуация | Метод |
|----------|-------|
| Основная масса p при ε → 0 | Разложение p₀ + ε²·p₁ + … |
| κ = 0 | Точный гаусс, не зависит от ε |
| κ ≠ 0, малый κ | Возмущение: p₀ + κ·q₀ + … |
| κ = O(1), нужна **p(r)** или **p(ω₁)** | **§13**: усреднение Хасминского по **θ** |
| Хвосты \|ω\| ≫ 1 | WKB / большие отклонения (вспомогательно) |
| Времена релаксации | Спектр L*: λ ~ ε² |

## 12. Полярные координаты

```
ω₁ = r · sin θ
ω₂ = r · cos θ
r² = ω₁² + ω₂² ,   r ≥ 0
```

Дрейф в полярных координатах:

```
b₁ = −κ · r² · sin θ · cos θ − ε² · α · r · sin θ
b₂ =  κ · r² · sin² θ   − ε² · α · r · cos θ
```

Ключевое свойство дрейфа:

```
ω₁·b₁ + ω₂·b₂ = −φ₀ · r² = −ε²·α · r²
```

Диссипация всегда направлена к меньшему r; члены с κ ортогональны радиусу при φ₀ = 0.

---

## 13. Усреднение по Хасминскому (κ = O(1))

При **κ = O(1)** и малом **ε** естественно разделить **быструю** угловую динамику и **медленную** радиальную (трение и шум входят как **ε²**).

### 13.1. Разделение масштабов времени

| Переменная | Порядок времени релаксации | Роль |
|-----------|----------------------------|------|
| **θ** | **O(1)** | быстрая (связь **κ**) |
| **r** | **O(1/ε²)** | медленная (трение **ε²α**, шум **εσ₀**) |

В полярных координатах (ω₁ = r sin θ, ω₂ = r cos θ):

```
dθ/dt = κ · sin θ  +  O(ε/r)     — быстрый дрейф (связь κ)
dr/dt = −ε² · α · r  +  O(ε)     — медленный дрейф
```

**Энергия** **E = r²/2**:

```
dE = −2·ε²·α·E  dt  +  ε²·σ₀²  dt  +  O(ε)  dW
```

### 13.2. Разложение генератора

Стационарный adjoint-оператор (УФПК):

```
L_ε^* = L_0^* + ε² L_1^*
```

```
L_0^* p = −∇·(b_D · p)                              — быстрый (угловой)
L_1^* p = −∇·(b_f · p) + (σ₀²/2) · Δp            — медленный
```

```
b_D = ( −κ·ω₁·ω₂ ,  κ·ω₁² ) ,   b_f = ( −α·ω₁ , −α·ω₂ )
```

Свойство **ω · b_D = 0**: дрейф **b_D** тангенциален → при фиксированном **r** действует только по **θ**.

### 13.3. Теорема Хасминского для системы (2.5)

Ниже — **явная формулировка** для стационарного УФПК системы (2.5) в режиме (2.7): **κ = O(1)**, **φ₀ = ε²α**, **σ = εσ₀**.

---

#### Постановка

Рассмотрим процесс **(ω₁^ε, ω₂^ε)** ∈ **ℝ²**, заданный (2.5):

```
dω₁ = ( −κ·ω₁·ω₂ − ε²·α·ω₁ ) dt + ε·σ₀ dW₁
dω₂ = (  κ·ω₁²   − ε²·α·ω₂ ) dt + ε·σ₀ dW₂
```

```
σ₀ = √(ν/A) ,   β = α·A/ν ,   κ = D/A
```

**Полярные координаты:** **ω₁ = r sin θ**, **ω₂ = r cos θ**, **r ≥ 0**, **θ ∈ [0, 2π)**.

**Быстрая переменная:** **θ** (время релаксации **O(1)**).

**Медленная переменная:** **r** (время релаксации **O(1/ε²)**):

```
dθ/dt = κ·sin θ + O(ε/r) ,   dr/dt = −ε²·α·r + O(ε)
```

**Стационарный adjoint-генератор** (§13.2):

```
L_ε^* = L_0^* + ε² L_1^*
L_0^* p = −∇·(b_D · p) ,   b_D = ( −κ·ω₁·ω₂ , κ·ω₁² )
L_1^* p = −∇·(b_f · p) + (σ₀²/2)·Δp ,   b_f = ( −α·ω₁ , −α·ω₂ )
```

---

#### Предпосылки (A)

Пусть выполнены:

| | Условие |
|---|---------|
| **(A1)** | **κ, α, ν, A > 0** фиксированы, **κ = O(1)** не зависит от **ε** |
| **(A2)** | **ε ∈ (0, ε₀]** — достаточно малый параметр (зависит от **κ, α, ν, A**) |
| **(A3)** | **σ = ε·σ₀ > 0** — изотропный шум; на каждой окружности **{r = const > 0}** процесс **θ** имеет единственную эргодическую инвариантную меру (§13.4) |
| **(A4)** | Существует единственная стационарная плотность **p^ε(ω₁, ω₂)** — сильная смесь: **p^ε ~ exp(−β\|ω\|²)** при **\|ω\| → ∞** |

*(A3) выполняется при **ε > 0** благодаря угловой диффузии **D_θ = ε²ν/(2A·r²) > 0**; при **ε = 0** дрейф **κ sin θ** неэргодичен.*

---

#### Усреднённый (лимитный) объект

**1. Условная угловая плотность** — стационарное решение быстрого оператора при фикс. **r > 0**:

```
L_0^* [ p₀(r) · q(θ | r) ] = 0     (в смысле §14, шаг 2)
```

```
q(θ | r) = exp( −Λ(r) · cos θ ) / ( 2π · I₀( Λ(r) ) )
Λ(r) = 2·κ·β·r² / ε²
```

**2. Маргинальная радиальная плотность** (мера **dr**):

```
f_R(r) = 2·β·r·exp( −β·r² ) ,   r ≥ 0
```

— единственное стационарное решение усреднённого 1D-УФПК (§13.5, §14 шаг 4):

```
−(d/dr)( α·r·f_R ) + (σ₀²/2)·(1/r)·(d/dr)( r·df_R/dr ) = 0
```

**3. Ведущая 2D-плотность** (мера **r dr dθ**):

```
p^(0)(r, θ) = f_R(r) · q(θ | r) / r
            = (β/π) · exp( −β·r² ) · exp( −Λ(r)·cos θ ) / I₀( Λ(r) )
```

**4. Предел при Λ → 0** (или **ε → 0** при фикс. **r**):

```
p^(0)(r, θ) → p₀(r) = (β/π) · exp( −β·r² )     (изотропный гаусс, §4)
```

---

#### Теорема (стационарное усреднение Хасминского)

**При предпосылках (A1)–(A4)** существуют константы **C, C_δ, C_T > 0** (не зависят от **ε** при **ε ≤ ε₀**) такие, что:

**(i) Факторизация стационарной плотности.**

Стационарная плотность **p^ε** допускает представление

```
p^ε(r, θ) = f_R(r) · q(θ | r) / r  +  ψ_ε(r, θ)
```

```
‖ ψ_ε ‖_{L¹(Ω_δ)}  ≤  C_δ · ε²     для любого   Ω_δ = { (r, θ) : r ≥ δ > 0 }
```

Эквивалентно (в декартовых координатах):

```
‖ p^ε − p^(0) ‖_{L¹(Ω_δ)}  ≤  C_δ · ε²
```

**(ii) Сходимость маргинальной по r.**

```
f_R^ε(r) = ∫₀^{2π} p^ε(r, θ) · r dθ     (маргинальная, мера dr)
```

```
‖ f_R^ε − f_R ‖_{L¹(0, ∞)}  ≤  C · ε²
```

**(iii) Сходимость условной угловой плотности.**

```
q^ε(θ | r) = p^ε(r, θ) · r / f_R^ε(r)
```

```
‖ q^ε(· | r) − q(· | r) ‖_{L²(0, 2π)}  ≤  C · ε²     (равномерно по r ∈ [δ, R] )
```

**(iv) Сходимость моментов.**

```
| E_ε[r²] − ν/(2·α·A) |  ≤  C · ε²
| E_ε[E] − ν/(4·α·A) |  ≤  C · ε²     ,   E = ½(ω₁² + ω₂²)
```

**(v) Динамическая формулировка (медленное время).**

В медленном времени **τ = ε²·t** процесс **r(τ)** сходится (в смысле слабой сходимости конечномерных распределений) к диффузии

```
dr = −α·r·dτ + σ₀·dW_τ
```

с инвариантной плотностью **f_R(r)**.

---

#### Замечания

**1. Область r = 0.** Оценки **(i)–(iii)** формулируются на **{r ≥ δ}**, поскольку полярные координаты вырождены при **r = 0**. Маргинальная **f_R(r) = 2βr exp(−βr²)** **регулярна** при **r = 0** — оценка **(ii)** глобальна по **r**.

**2. Порядок O(ε²).** Поправка **O(ε²)**, а не **O(ε)**, поскольку медленная динамика (трение и шум) входит в (2.5) как **ε²** (§13.1).

**3. Связь с §14.** Явные **q(θ|r)**, **f_R**, **p^(0)** — результат **алгоритма** Хасминского (шаги 1–5); теорема утверждает, что **p^ε** **с ε-точностью O(ε²)** совпадает с этим объектом.

**4. Что теорема не утверждает.** Поправки **p₁ = −κp₀/r**, **p₂** (§7–8, §15) — **следующий** порядок **Чепмена–Энскога**, **не** входят в **p^(0)**. Сходимость **формального ряда** **∑ ε^{2k} p^(k)** — отдельный вопрос (§17).

**5. Литература.** Стандартная схема доказательства: Khasminskii (1966); Freidlin–Wentzell; Pavliotis–Stuart, *Multiscale Methods*, гл. 17–18. Для данной системы — частный случай **быстрый угол / медленный радиус** с **confining** потенциалом **βr²**.

---

#### Следствие (ведущий порядок в декартовых координатах)

```
p^ε(ω₁, ω₂) = (β/π) · exp( −β·(ω₁² + ω₂²) ) · exp( −Λ(r)·ω₂/r ) / I₀( Λ(r) )  +  O(ε²)
```

```
r = √(ω₁² + ω₂²) ,   Λ(r) = 2κβr²/ε²
```

При **Λ(r) ≪ 1**:

```
p^ε(ω₁, ω₂) = p₀(ω₁, ω₂) + O(ε²)     ,   p₀ = (β/π) exp( −β·(ω₁² + ω₂²) )
```

---

### 13.4. Условие эргодичности по θ

При **ε = 0** (без шума) на окружности **r = const**:

```
dθ/dt = κ · sin θ
```

процесс **неэргодичен** (неподвижные точки **θ = 0, π**). Для **ε > 0** шум **σ = εσ₀ > 0** делает **(θ | r)** эргодическим на **[0, 2π)** — условие Хасминского выполняется при достаточно малых **ε**.

### 13.5. Усреднённое уравнение для p_r(r)

Усредняем медленный оператор **L_1^*** по **θ** при фиксированном **r**:

```
(b_f)_r = −α · r · sin θ   (радиальная проекция трения)
D_r = σ₀²                  (изотропный шум)
```

На ведущем порядке (усреднение по **θ**):

```
b̄(r) = −α · r ,   D̄ = σ₀²
```

**Эффективное 1D-УФПК** для маргинальной **f_R(r)** (мера **dr**, якобиан **r dr dθ**):

```
−(d/dr)( α · r · f_R ) + (σ₀²/2) · (1/r) · (d/dr)( r · d f_R / dr ) = 0
```

Решение — **маргинальная плотность радиуса** (мера **dr**):

```
f_R(r) = 2·β · r · exp( −β · r² ) ,   r ≥ 0
```

**2D-плотность** при равномерном **θ** (ведущий порядок):

```
p^ε(r, θ)  ≈  f_R(r) / (2π·r)  =  (β / π) · exp( −β · r² )  =  p₀
```

**Средняя энергия:**

```
E[r²] = ν / (2·α·A) ,   E[E] = ν / (4·α·A) ,   E = ½(ω₁² + ω₂²)
```

— совпадает с режимом (2.7).

### 13.6. Восстановление 2D-плотности

**Ведущий порядок** (изотропное усреднение по **θ**):

```
p^ε(ω₁, ω₂)  ≈  p₀(ω₁, ω₂)  =  (β / π) · exp( −β · (ω₁² + ω₂²) )
```

Маргинальная по **r**: **f_R(r) = 2β r exp(−β r²)**.  
В декартовых координатах: **r = √(ω₁² + ω₂²)**.

**Поправки O(ε²):** угловая неоднородность **q(θ | r) ≠ const** и связь **κ** — из разложения Чепмена–Энскога / поправки **p₁ ~ −κp₀/r** в разделе 7–8.

### 13.7. Хасминский vs разложение по ε

| | Разложение **p₀ + ε²p₁ + …** | Хасминский |
|---|---|---|
| **Область** | **(ω₁, ω₂)** целиком | маргинальная **p(r)**, **p(ω₁)** |
| **κ = O(1)** | **p₁ ~ −κ/r**, сингулярность у **r = 0** | **p_r(r)** без **1/r**, **r ≥ 0** |
| **Угол θ** | явно в **p₂ ~ cos θ** | усреднён: **1/(2π)** на ведущем порядке |
| **Когда** | локальная асимптотика в **r = O(1)** | глобальная картина **p(r)**, **E[r²]** |

### 13.8. Алгоритм (кратко)

```
1. Выделить быструю θ и медленную r  (или E = r²/2).
2. Найти q(θ | r) из L_0^* q = 0  (с O(ε²)-поправками).
3. Вычислить усреднённые b̄(r), D̄(r).
4. Решить 1D-УФПК для f_R(r).
5. p(ω₁, ω₂) ≈ f_R(r) · q(θ | r) / r.
6. Поправки O(ε²) — разложение Чепмена–Энскога.
```

## 14. Выполнение алгоритма Хасминского (явно)

### Шаг 1. Быстрая θ и медленная r

**Полярные координаты:** ω₁ = r sin θ, ω₂ = r cos θ, r ≥ 0.

Из (2.5) в полярной форме (главные члены):

```
b_r = −ε² · α · r                    — радиальный дрейф (только трение)
b_θ = κ · r² · sin θ                 — тангенциальный дрейф (связь κ)
```

```
dθ/dt = b_θ / r² = κ · sin θ         — O(1), быстрая переменная
dr/dt = b_r = −ε² · α · r            — O(ε²), медленная переменная
```

**Шум:** **σ = ε·σ₀**, изотропный → радиальная и угловая диффузия порядка **ε²**.

**Масштабы времени:**

| Переменная | τ |
|-----------|---|
| **θ** | **O(1)** |
| **r** | **O(1/ε²)** |
| **E = r²/2** | **O(1/ε²)** |

---

### Шаг 2. Угловая плотность q(θ | r)

**Быстрый adjoint-оператор** при фиксированном **r**:

```
L_0^* q = −(1/r) · ∂/∂θ ( b_θ · q ) + O(ε²)
```

На ведущем порядке — **1D-УФПК на окружности** (угол **θ**, параметр **r**):

```
∂/∂θ ( κ · sin θ · q  −  D_θ(r) · ∂q/∂θ ) = 0
```

**Угловая диффузия** (из изотропного шума **ε·σ₀** при фикс. **r**):

```
D_θ(r) = ε² · σ₀² / (2 · r²) = ε² · ν / (2 · A · r²)
```

**Решение** (нормировка **∫₀^{2π} q dθ = 1**):

```
q(θ | r) = (1 / Z(r)) · exp( −Λ(r) · cos θ )
```

```
Λ(r) = κ / D_θ(r) = 2 · κ · r² · A / (ε² · ν) = 2 · κ · β · r² / ε²
```

**Нормировочная константа** (модифицированная функция Бesselel):

```
Z(r) = ∫₀^{2π} exp( −Λ(r) · cos θ ) dθ = 2π · I₀( Λ(r) )
```

**Пределы:**

```
Λ → 0  (ε → 0 при фикс. r):   q(θ | r) → 1/(2π)     (равномерное)
Λ ≫ 1:                        q концентрируется у θ = 0  (cos θ = 1)
```

**O(ε²)-поправка к q:** учёт **L_1^*** в уравнении для **q** даёт **q = q₀ + ε² q₁ + …** (разложение Чепмена–Энскога на быстром масштабе).

---

### Шаг 3. Усреднённые b̄(r) и D̄(r)

Усредняем **L_1^*** по **q(θ | r)**:

```
⟨f⟩_q = ∫₀^{2π} f(θ) · q(θ | r) dθ
```

**Радиальный дрейф** (из **b_f**):

```
e_r = ( sin θ , cos θ )     (единичный «радиальный» вектор)
b_f · e_r = −α · r · ( sin²θ + cos²θ ) = −α · r
```

```
b̄(r) = ⟨b_f · e_r⟩_q = −α · r          — не зависит от q
```

**Диффузия** (изотропная):

```
D̄(r) = σ₀² = ν / A                     — на ведущем порядке
```

**Усреднённый медленный SDE** (в медленном времени **τ = ε²·t**):

```
dr = −α · r · dτ  +  σ₀ · dW_τ
```

---

### Шаг 4. 1D-УФПК для f_R(r)

**Стационарное уравнение** для маргинальной плотности **f_R(r)** (мера **dr**):

```
−(d/dr)( α · r · f_R ) + (σ₀²/2) · (1/r) · (d/dr)( r · d f_R / dr ) = 0
```

**Решение:**

```
f_R(r) = 2 · β · r · exp( −β · r² ) ,   r ≥ 0 ,   β = α·A / ν
```

**Проверка моментов:**

```
E[r²] = ∫₀^∞ r² · f_R(r) dr = ν / (2·α·A)
E[E] = E[r²/2] = ν / (4·α·A)
```

---

### Шаг 5. Восстановление p(ω₁, ω₂)

**Связь** **f_R**, **q** и **2D-плотности** (мера **r dr dθ**):

```
p(r, θ) = f_R(r) · q(θ | r) / r
```

**Подстановка** **f_R**:

```
p(r, θ) = 2 · β · exp( −β · r² ) · q(θ | r)
```

**Сравнение с p₀:**

```
p₀ = (β/π) · exp( −β · r² )
p(r, θ) = p₀(r) · 2π · q(θ | r)
```

**При равномерном q = 1/(2π):**

```
p(r, θ) = p₀(r) = (β/π) · exp( −β · r² )     — гаусс
```

**В декартовых координатах:**

```
p(ω₁, ω₂) = 2 · β · exp( −β · (ω₁² + ω₂²) ) · q( θ(ω₁, ω₂) | r ) / (2π)
```

```
r = √(ω₁² + ω₂²) ,   cos θ = ω₂ / r ,   sin θ = ω₁ / r
```

**Явная формула с Bessel:**

```
p(ω₁, ω₂) = (β/π) · exp( −β · r² ) · exp( −Λ(r) · cos θ ) / I₀( Λ(r) )
```

```
Λ(r) = 2 · κ · β · r² / ε²
```

---

### Шаг 6. Поправки O(ε²) — Чепмен–Энског

Подробный вывод **p₁**, **p₂** и связь с §7–8 — в **§15**.

---

## 15. Чепмен–Энског: явные p₁, p₂ и связь с §7–8

### 15.1. Разложение (согласованное с §3, §7, §8, §14)

```
p^ε(ω₁, ω₂) = p₀(r) · q(θ | r)  +  ε² · p₁(r, θ)  +  ε⁴ · p₂(r, θ)  +  O(ε⁶)
```

```
p₀(r) = (β / π) · exp( −β · r² )
q(θ | r) = exp( −Λ · cos θ ) / ( 2π · I₀(Λ) )     — §14, шаг 2
```

**Эквивалентная форма через множители** (как в §8):

```
p^ε = p₀(r) · [ q(θ | r)  +  ε² · Ψ₁(r, θ)  +  ε⁴ · Ψ₂(r, θ)  +  … ]
```

---

### 15.2. Иерархия Чепмена–Энскога

```
L_ε^* = L_0^* + ε² · L_1^*
```

```
L_0^* p = −∇·(b_D · p)                         — быстрый (угол θ)
L_1^* p = −∇·(b_f · p) + (σ₀²/2) · Δp        — медленный (трение + шум)
```

**Разложение:**

```
p^ε = p^(0) + ε² · p^(1) + ε⁴ · p^(2) + O(ε⁶)
```

| Порядок | Уравнение |
|---------|-----------|
| **O(1)** | **L_0^* p^(0) = 0** |
| **O(ε²)** | **L_0^* p^(1) = −L_1^* p^(0) − G(p^(0))** |
| **O(ε⁴)** | **L_0^* p^(2) = −L_1^* p^(1) − G(p^(1)) + ⟨…⟩** |

```
G(p) = ∇·(b_D · p)     — «несогласованность» гауссового p₀ с b_D
```

**Ключевой факт (§6–7):** **L_1^* p₀ = 0**, но **G(p₀) = κ · ω₂ · p₀ = κ · r · cos θ · p₀**.

---

### 15.3. Ведущий член p^(0)

```
p^(0)(r, θ) = p₀(r) · q(θ | r)
```

При **Λ → 0**: **q → 1/(2π)**, **p^(0) → p₀** (гаусс, §4).

---

### 15.4. Поправка O(ε²): явный p₁

**Анзац** (разделение радиальной и угловой частей):

```
p₁ = p₀(r) · [  Q_r(r)  +  Q_θ(θ | r)  ]
```

**Подстановка** **p₁ = p₀ · Q** в уравнение O(ε²):

```
∇·(b_D · p₁) + L_1^* p₁ = −G(p₀) = −κ · r · cos θ · p₀
```

При **b_D · ∇p₀ = 0** (§7):

```
p₀ · [ ∇·(b_D · Q) + L_1^* Q · p₀/p₀ ] = −κ · r · cos θ · p₀
```

**Частное решение по радиальной части** (§7, проверка §7):

```
Q_r(r) = −κ / r
```

```
∇·(b_D · Q_r) = κ · ω₂ = κ · r · cos θ     (при b_D с коэффициентом κ)
```

```
p₁^sing(r, θ) = −κ · p₀(r) / r              — §7, сингулярная часть
```

**Однородное (угловое) дополнение Q_θ** — решение:

```
L_0^* (p₀ · Q_θ) = 0 ,   ∫₀^{2π} Q_θ · q(θ|r) dθ = 0
```

На практике **Q_θ = O(κ²/ε²)** мало при **Λ ≪ 1**; **ведущий член p₁ — радиальный**.

**Итог O(ε²):**

```
p₁(r, θ) = −κ · p₀(r) / r  +  p₀(r) · Q_θ(θ | r)  +  O(κ²/ε²)
```

**В декартовых координатах** (§7):

```
p₁(ω₁, ω₂) = −κ · (β/π) · exp( −β·(ω₁² + ω₂²) ) / √(ω₁² + ω₂²)
```

**Связь с §14:** **p₁^sing ~ −κ/r** — локальная поправка Чепмена–Энскога; **q(θ|r)** из Хасминского — в **p^(0)**, не в **p₁**.

---

### 15.5. Поправка O(ε⁴): явный p₂ и связь с cos θ

**Уравнение O(ε⁴):**

```
∇·(b_D · p₂) + L_1^* p₂ = −∇·(b_D · p₁) − L_1^* p₁
```

**Правая часть** при **p₁ = −κ p₀/r** (§8, вычислено):

```
−∇·(b_D · p₁) − L_1^* p₁  =  p₀ · [ α·κ/r  +  κ²·r·cos θ  +  κ·ν/(2·A·r³) ]
```

**Анзац** (§8):

```
p₂ = p₀(r) · [  κ² / (2·r²)  +  κ² · cos θ / (2·α)  +  Q₂^c(r, θ)  ]
```

| Член | Источник | Зависимость от θ |
|------|----------|------------------|
| **κ²/(2r²)** | нелинейная итерация **Q_r = −κ/r**; **Q_r²/2** в **p = p₀(1 + ε²Q_r + …)** | нет |
| **κ² cos θ/(2α)** | баланс члена **κ² r cos θ** в правой части O(ε⁴) | **∝ cos θ = ω₂/r** |
| **Q₂^c** | однородное / нормировка | O(1) |

**Явные формулы §8 (полярные, ω₁ = r sin θ, ω₂ = r cos θ):**

```
p₂(r, θ) = (β/π) · exp( −β·r² ) · [ κ²/(2·r²)  +  κ²·cos(θ)/(2·α) ]
```

**В декартовых координатах:**

```
p₂(ω₁, ω₂) = (β/π) · exp( −β·(ω₁² + ω₂²) ) · [
    κ² / ( 2·(ω₁² + ω₂²) )
  + κ²·ω₂ / ( 2·α·(ω₁² + ω₂²)^(3/2) )
]
```

---

### 15.6. Единая формула (Хасминский + Чепмен–Энског)

```
p^ε(ω₁, ω₂) = p₀(r) · exp( −Λ · cos θ ) / I₀(Λ)
              − ε² · κ · p₀(r) / r
              + ε⁴ · p₀(r) · [ κ²/(2·r²) + κ²·cos(θ)/(2α) ]
              + O(ε⁶)
```

```
r = √(ω₁² + ω₂²) ,   cos θ = ω₂/r ,   Λ = 2κβr²/ε²
```

**Разделение ролей:**

| Объект | Масштаб | Метод | § |
|--------|---------|-------|---|
| **p₀ exp(−Λ cos θ)/I₀** | O(1) | Хасминский, **q(θ\|r)** | §14 |
| **−ε² κ p₀/r** | O(ε²) | Чепмен–Энског, **G(p₀)** | §7, §15.4 |
| **ε⁴ p₀ κ² cos θ/(2α)** | O(ε⁴) | Чепмен–Энског, угловая гармоника | §8, §15.5 |
| **ε⁴ p₀ κ²/(2r²)** | O(ε⁴) | Чепмен–Энског, **Q_r²/2** | §8, §15.5 |

---

### 15.7. Мультипликативная форма (связь p₁ и p₂)

```
p^ε ≈ p₀(r) · q(θ | r) · exp( ε² · Q₁ + ε⁴ · ( Q₂ + Q₁²/2 ) + … )
```

```
Q₁ = −κ / r
Q₂ + Q₁²/2  →  Q₂ + κ²/(2r²)   на уровне ε⁴
```

Угловой член **κ² cos θ/(2α)** не выводится из **Q₁** alone — он идёт из **L_1^* p₁** (связь **κ** и **α**).

---

### 15.8. Сводная таблица p₁, p₂

| | **p₁ (ε²)** | **p₂ (ε⁴)** |
|---|---|---|
| **§7–8 (декарт.)** | **−κ p₀/r** | **p₀[κ²/(2r²) + κ²ω₂/(2αr)]** |
| **§15 (полярн.)** | **−κ p₀/r** | **p₀[κ²/(2r²) + κ² cos θ/(2α)]** |
| **CE источник** | **G(p₀) = κω₂ p₀** | **−∇·(b_D p₁) − L_1 p₁** |
| **θ-зависимость** | только в **Q_θ** (малый) | **∝ cos θ** в ведущем угловом члене |

## 16. Сравнение: формальный ряд и Хасминский + Чепмен–Энског

Обозначения общие:

```
r = √(ω₁² + ω₂²) ,   ω₁ = r sin θ ,   ω₂ = r cos θ ,   cos θ = ω₂/r
p₀ = (β/π) · exp( −β·r² ) ,   β = α·A/ν ,   Λ = 2κβr²/ε²
Z(ε) = 1 − ε²·κ·√(βπ) + O(ε⁴)
```

---

### 16.1. Два представления p^ε

| | **Формальный ряд (§3, §8)** | **Хасминский + CE (§14–§15)** |
|---|---|---|
| **Идея** | разложение **вокруг гаусса p₀** | **усреднение по θ** + локальные поправки CE |
| **O(1)** | **p₀** (изотропный гаусс) | **p₀ · exp(−Λ cos θ) / I₀(Λ)** |
| **O(ε²)** | **p₁ = −κ p₀/r** | **−ε² κ p₀/r** (то же) |
| **O(ε⁴)** | **p₂ = p₀[κ²/(2r²) + κ² cos θ/(2α)]** | **ε⁴ p₀[κ²/(2r²) + κ² cos θ/(2α)]** (то же) |
| **Нормировка** | деление на **Z(ε)** | в §15.6 явно **без Z(ε)**; глобальная норма из **f_R** |
| **Угол на O(1)** | нет | **q(θ\|r) ≠ const** при **Λ = O(1)** |

**Формальный ряд** — прямое разложение стационарного УФПК по **ε²** в декартовых **(ω₁, ω₂)**.

**Хасминский + CE** — сначала **2D → (r, θ)** с явной **q(θ\|r)**, затем те же **p₁, p₂** из иерархии CE.

---

### 16.2. Формальный ряд p^ε (декартовы координаты)

**Общий вид:**

```
p^ε_form(ω₁, ω₂) = (1 / Z(ε)) · [ p₀ + ε²·p₁ + ε⁴·p₂ + O(ε⁶) ]
```

**Явно** (§8, **r = √(ω₁² + ω₂²)**):

```
p^ε_form(ω₁, ω₂) = (1 / Z(ε)) · (β/π) · exp( −β·(ω₁² + ω₂²) ) · {
    1
  − ε² · κ / r
  + ε⁴ · [ κ²/(2·r²) + κ²·ω₂ / (2·α·r) ]
  + O(ε⁶)
}
```

| Член | Зависимость от **ω₁, ω₂** |
|------|---------------------------|
| **p₀** | только **r² = ω₁² + ω₂²** |
| **p₁** | только **r** (радиально-симметричный) |
| **p₂** | **r** и **ω₂** (через **cos θ = ω₂/r**) |

**Мультипликативная форма:**

```
p^ε_form = (β / πZ(ε)) · exp( −β·r² ) · [ 1 − ε²·κ/r + ε⁴·Q₂ + O(ε⁶) ]
Q₂ = κ²/(2·r²) + κ²·ω₂/(2·α·r)
```

---

### 16.3. Формальный ряд p^ε (полярные координаты)

```
p^ε_form(r, θ) = (1 / Z(ε)) · (β/π) · exp( −β·r² ) · {
    1
  − ε² · κ / r
  + ε⁴ · [ κ²/(2·r²) + κ²·cos(θ)/(2·α) ]
  + O(ε⁶)
}
```

**Развёрнуто:**

```
p^ε_form(r, θ) = (1/Z(ε)) · {
    (β/π)·exp(−β·r²)
  − ε²·κ·(β/π)·exp(−β·r²)/r
  + ε⁴·(β/π)·exp(−β·r²)·[κ²/(2·r²) + κ²·cos(θ)/(2·α)]
  + O(ε⁶)
}
```

На порядках **ε², ε⁴** угол **θ** входит **только в p₂** (член **∝ cos θ**).

---

### 16.4. Хасминский + CE (декартовы координаты)

**Сложение** (§15.6):

```
p^ε_KH+CE(ω₁, ω₂) = p₀(r) · exp( −Λ(r)·cos θ ) / I₀( Λ(r) )
                    − ε² · κ · p₀(r) / r
                    + ε⁴ · p₀(r) · [ κ²/(2·r²) + κ²·ω₂/(2·α·r) ]
                    + O(ε⁶)
```

**Подстановка** **r, cos θ = ω₂/r**:

```
p^ε_KH+CE(ω₁, ω₂) = (β/π) · exp( −β·r² ) · exp( −Λ·ω₂/r ) / I₀(Λ)
                    − ε²·κ·(β/π)·exp(−β·r²)/r
                    + ε⁴·(β/π)·exp(−β·r²)·[κ²/(2·r²) + κ²·ω₂/(2·α·r)]
                    + O(ε⁶)
```

**Мультипликативная форма** (§15.7):

```
p^ε_KH+CE ≈ p₀(r) · [ exp(−Λ cos θ)/I₀(Λ) − ε²·κ/r + ε⁴·(κ²/(2r²) + κ²·ω₂/(2α·r)) ]
```

---

### 16.5. Хасминский + CE (полярные координаты)

```
p^ε_KH+CE(r, θ) = (β/π) · exp( −β·r² ) · exp( −Λ(r)·cos θ ) / I₀( Λ(r) )
                  − ε² · κ · (β/π) · exp( −β·r² ) / r
                  + ε⁴ · (β/π) · exp( −β·r² ) · [ κ²/(2·r²) + κ²·cos(θ)/(2·α) ]
                  + O(ε⁶)
```

**Связь с шагами §14:**

```
p^ε_KH+CE = f_R(r)/r · q(θ|r)  −  ε²·p₁  +  ε⁴·p₂  +  O(ε⁶)
f_R(r) = 2βr exp(−βr²) ,   q(θ|r) = exp(−Λ cos θ)/(2π I₀(Λ))
f_R/r = 2β exp(−βr²) = 2π · p₀     →     f_R/r · q = p₀ · exp(−Λ cos θ)/I₀
```

---

### 16.6. Побайтовое сравнение (полярные)

| Порядок | **Формальный ряд** | **Хасминский + CE** | Совпадение? |
|---------|-------------------|---------------------|-------------|
| **O(1)** | **p₀ = (β/π) exp(−βr²)** | **p₀ · exp(−Λ cos θ)/I₀(Λ)** | **да**, если **Λ → 0** (**exp(−Λ cos θ)/I₀ → 1**) |
| **O(ε²)** | **−κ p₀/r** (÷ **Z(ε)**) | **−κ p₀/r** | **да** (разница **Z(ε) − 1 = O(ε²)**) |
| **O(ε⁴)** | **p₀[κ²/(2r²) + κ² cos θ/(2α)]** | то же | **да** |
| **Нормировка** | **1/Z(ε)** | без **Z** в §15.6 | поправка **O(ε²)** |

**Разложение Bessel при малом Λ:**

```
exp(−Λ cos θ)/I₀(Λ) = 1 − Λ·cos θ + O(Λ²)     ,   Λ = 2κβr²/ε²
```

Угловая неоднородность **O(1)** в **KH+CE** **не входит** в формальный ряд на уровне **p₀** — она «спрятана» в быстром масштабе **θ** и появляется в **q(θ\|r)**.

---

### 16.7. Побайтовое сравнение (декартовы)

Подставляем **r = √(ω₁² + ω₂²)**, **ω₂ = r cos θ**:

| | **p^ε_form(ω₁, ω₂)** | **p^ε_KH+CE(ω₁, ω₂)** |
|---|---|---|
| **O(1)** | **(β/π) exp(−β(ω₁²+ω₂²))** | **(β/π) exp(−βr²) · exp(−Λ·ω₂/r) / I₀(Λ)** |
| **O(ε²)** | **−ε² κ (β/π) exp(−βr²)/r** | **−ε² κ (β/π) exp(−βr²)/r** |
| **O(ε⁴)** | **ε⁴ (β/π) exp(−βr²)·[κ²/(2r²)+κ²ω₂/(2αr)]** | **ε⁴ (β/π) exp(−βr²)·[κ²/(2r²)+κ²ω₂/(2αr)]** |
| **Множитель** | **1/Z(ε)** | **1** (в §15.6) |

**Члены ε² и ε⁴ совпадают**; отличие на **O(1)** — угловой множитель **exp(−Λ·ω₂/r)/I₀(Λ)** против **1**.

---

### 16.8. Когда представления согласуются

**1. Предел ε → 0 при фикс. r = O(1):**

```
Λ = 2κβr²/ε² → ∞    (формально)
```

На практике **согласование** проверяют при **Λ ≪ 1** (малый **κ**, большой **ε**, или **r ≪ ε/√(2κβ)**):

```
p^ε_KH+CE → p₀ − ε²κp₀/r + ε⁴ p₀[κ²/(2r²)+κ² cos θ/(2α)]   ≈   p^ε_form / Z(ε)
```

**2. Маргинальная по r:**

Формальный ряд после интегрирования по **θ** (или по **ω₂**):

```
∫ p^ε_form · r dr dθ  →  f_R(r) = 2βr exp(−βr²)   на ведущем порядке
```

Хасминский **f_R** **точно** даёт **2βr exp(−βr²)** — совпадение **E[r²] = ν/(2αA)**.

**3. Область r = O(1), κ = O(1):**

Оба описания — **формальная асимптотика**; **p₁ ~ 1/r** сингулярен у **r = 0** в обоих случаях.

**4. Глобально по r:**

**KH+CE** предпочтительнее: **f_R(r)** корректен при **r ≥ 0** без **1/r** в ведущей маргинальной; **q(θ\|r)** даёт физичную угловую структуру при **Λ = O(1)**.

---

### 16.9. Сводная таблица (обе системы координат)

| Величина | **Формальный ряд** (декарт / поляр) | **KH + CE** (декарт / поляр) |
|----------|-------------------------------------|------------------------------|
| **p₀** | **(β/π) exp(−βr²)** | **(β/π) exp(−βr²) · exp(−Λ cos θ)/I₀(Λ)** |
| **p₁** | **−κ p₀/r** | **−κ p₀/r** |
| **p₂** | **p₀[κ²/(2r²) + κ²ω₂/(2αr)]** / **p₀[κ²/(2r²)+κ² cos θ/(2α)]** | то же |
| **Полная (усеч.)** | **(1/Z(ε))·[p₀+ε²p₁+ε⁴p₂]** | **p₀·exp(−Λ cos θ)/I₀ − ε²κp₀/r + ε⁴p₂** |
| **θ на O(1)** | нет | **exp(−Λ cos θ)/I₀** |
| **θ на O(ε⁴)** | **∝ cos θ** | **∝ cos θ** |
| **Сингулярность r=0** | **p₁ ~ 1/r** | **p₁ ~ 1/r** |
| **§ в файле** | §3, §7, §8 | §14, §15 |

---

### 16.10. Итог

- **p₁ и p₂** (явные формулы CE) **одинаковы** в обоих подходах и в декартовых, и в полярных координатах.
- **Различие на O(1):** формальный ряд начинает с **изотропного p₀**; **KH+CE** включает **угловую неоднородность q(θ\|r)** уже на ведущем порядке.
- **Различие в нормировке:** формальный ряд делит на **Z(ε) = 1 − ε²κ√(βπ) + …**; в §15.6 **Z** не выписан — поправка того же порядка **O(ε²)**, что и **p₁**.
- **Практика:** для **локальной** картины при **r = O(1)**, **Λ ≪ 1** — формулы §8 и §15.6 **эквивалентны** с точностью **O(ε⁴)**; для **глобальной p(r)** и **угла при Λ = O(1)** — **KH+CE** полнее.

## 17. Теоретическое обоснование: сходимость и оценки ошибки

Краткий ответ: **частично да** — ведущий **хасминский** блок имеет стандартное обоснование; поправки **Чепмена–Энскога** (**p₁, p₂**) — **формальная асимптотика** с эвристическими, но не полностью доказанными оценками остатка.

---

### 17.1. Что строго обосновано (Хасминский)

**Стандартная постановка:** быстрая переменная **θ** (время **O(1)**), медленная **r** (время **O(1/ε²)**), шум **σ = εσ₀ > 0**.

**Условия (§13.4):** при **ε > 0** процесс **(θ | r)** на окружности **эргодичен** (изотропная диффузия **D_θ = ε²ν/(2Ar²) > 0**); confining-потенциал **βr²** обеспечивает интегрируемость.

**Теорема усреднения (схема, §13.3):** при **ε → 0**

```
p^ε(r, θ)  →  f_R(r) · q(θ | r) / r     (слабо или в подходящей норме)
```

**Маргинальная по r:**

```
f_R(r) = 2β r exp(−βr²)     — стационарное решение усреднённого 1D-УФПК (§14, шаг 4)
```

**Типичная оценка остатка** (классические результаты усреднения, см. Khasminskii; Freidlin–Wentzell; Pavliotis–Stuart):

```
‖ f_R^ε − f_R ‖_{L¹(0,∞)}  =  O(ε²)
```

```
‖ q^ε(·|r) − q(·|r) ‖_{L²(0,2π)}  =  O(ε²)     (при фикс. r > 0)
```

**2D-ведущий член** **p^(0) = p₀ · exp(−Λ cos θ)/I₀(Λ)**:

```
‖ p^ε − p^(0) ‖_{L¹( compact )}  =  O(ε²)     (на компактах, r ≥ δ > 0)
```

**Моменты** (**E[r²]**, **E[E]**) восстанавливаются из **f_R** **точно** на ведущем порядке — это **жёсткая** проверка усреднения.

| Объект | Статус | Типичная оценка |
|--------|--------|-----------------|
| **f_R(r)** | усреднение Хасминского | **O(ε²)** |
| **q(θ\|r)** | инвариантная мера **L₀\*** | **O(ε²)** поправки к **q** |
| **p^(0) = p₀·exp(−Λ cos θ)/I₀** | факторизация §14 | **O(ε²)** на **{r ≥ δ}** |
| **E[r²], E[E]** | из **f_R** | **O(ε²)** или лучше |

---

### 17.2. Что формально (Чепмен–Энског)

Иерархия **L_ε\* = L₀\* + ε² L₁\*** (§15.2) даёт **формальное** разложение:

```
p^ε  ~  p^(0) + ε² p^(1) + ε⁴ p^(2) + …
p^(1) = p₁ = −κ p₀/r ,   p^(2) = p₂  — §7–8, §15
```

**Нет общей теоремы** о **сходимости** ряда **∑ ε^{2k} p^(k)** для данного **L_ε\***.

**Что гарантирует CE на каждом шаге (формально):**

1. **Условие разрешимости** **⟨L₁\* p^(k) + …⟩_θ = 0** (Fredholm) — определяет **p^(k+1)** с точностью до однородных решений **L₀\* φ = 0**.
2. **p₁, p₂** — **первые согласованные** члены; следующий **p₃** требует отдельного вычисления.
3. Ряд, как правило, **асимптотический**, не **сходящийся** при фикс. **r** и **κ = O(1)**.

**Статус явных формул:**

| Член | Вывод | Строгость |
|------|-------|-----------|
| **p₁ = −κp₀/r** | частное решение **G(p₀) = κω₂ p₀** | формально; **1/r** — сингулярность |
| **p₂ ~ κ²/(2r²) + κ² cos θ/(2α)** | баланс O(ε⁴) | формально; главные члены |
| **Z(ε)** | нормировка **∬ p dω = 1** | формально **O(ε²)** |

---

### 17.3. Составное представление KH + CE (§15.6)

```
p^ε  ≈  p^(0)  −  ε² κ p₀/r  +  ε⁴ p₂  +  O(ε⁶)
```

**Разделение ответственности за оценку:**

| Часть | Метод | Оценка остатка (ожидаемая) |
|-------|-------|----------------------------|
| **p^(0)** | Хасминский | **O(ε²)** глобально по **r** (маргиналь); **O(ε²)** по **θ** |
| **−ε² κ p₀/r** | CE | улучшает **2D** на **{r ≥ δ}** до **O(ε⁴)** (не доказано для данной системы) |
| **ε⁴ p₂** | CE | **O(ε⁶)** на **{r ≥ δ}** (формально) |

**Схема доказательства** (не выполнена в этом файле полностью):

```
‖ p^ε − p^(0) − ε² p₁ − ε⁴ p₂ ‖_{L¹(Ω_δ)}  =  O(ε⁶)     ,   Ω_δ = { r ≥ δ > 0 }
```

```
‖ p^ε − p^(0) − ε² p₁ − ε⁴ p₂ ‖_{L¹(ℝ²)}  =  O(ε⁴)  или  O(ε²)
```

— зависит от **слоя у r = 0** (сингулярность **p₁**).

---

### 17.4. Сингулярность у r = 0 (главное препятствие)

**p₁ ~ −κ/r** не интегрируема вблизи начала координат:

```
∬_{r<δ} |p₁| dω  ~  ∫₀^δ r · (1/r) dr  ~  O(δ)     — конечно
```

но формальный ряд **не** описывает **внутренний слой** **r ~ O(ε)** или **r ~ O(ε²)**.

**Для строгой L¹-оценки** нужно:

1. **Внешнее** разложение (§7–8, §15) на **{r ≥ δ}**.
2. **Внутреннее** разложение в переменной **ρ = r/ε** (или **r/ε²**) у **r = 0**.
3. **Сшивка** (matching) и единая нормировка.

**Без внутреннего слоя:** глобальная оценка **‖p^ε − (p^(0) − ε²κp₀/r + ε⁴p₂)‖_{L¹}** — **не лучше O(ε²)** в общем случае.

**Хасминский** обходит это для **маргинальной f_R(r)**: **2βr exp(−βr²)** **регулярна** при **r = 0** — поэтому **p(r)** обоснован **глобально**, а **2D-поправки CE** — **локально** (или с layer).

---

### 17.5. Сравнение с формальным рядом (§16)

| Вопрос | Формальный ряд | KH + CE |
|--------|----------------|---------|
| **Сходимость ряда** | **нет** (формальный) | **нет** (CE-часть) |
| **Оценка ведущего члена** | **p₀** — точен при **κ=0** | **p^(0)** — **O(ε²)** от **p^ε** |
| **Маргинальная p(r)** | из интегрирования ряда | **f_R** — **O(ε²)** (Хасминский) |
| **Моменты E[r²]** | **O(ε²)** из **Z(ε)** | **O(ε²)** из **f_R** |
| **Глобальная L¹-оценка усечения** | нужен layer у **r=0** | **p^(0)** — да; с **p₁** — нужен layer |

**Практический вывод:** **KH + CE** **теоретически сильнее** для **p(r)** и **q(θ\|r)**; **p₁, p₂** добавляют **эвристически согласованные** поправки к **2D**, но **полная** **L¹-оценка** **O(ε⁴)** для усечения §15.6 **не доказана** здесь.

---

### 17.6. Достаточные условия (чеклист для строгого proof)

Для **полного** обоснования **p^ε ≈ p^(0) − ε²κp₀/r + ε⁴p₂** потребовалось бы:

| № | Условие | Статус для (2.5) |
|---|---------|------------------|
| 1 | Эргодичность **(θ\|r)** при **ε > 0** | **да** (§13.4) |
| 2 | Confining: **p^ε** быстро убывает при **\|ω\| → ∞** | **да** (**β > 0**) |
| 3 | Гладкость коэффициентов при **r > 0** | **да** |
| 4 | Оценка **O(ε²)** для **f_R**, **q** (Хасминский) | стандартно, **не расписано** |
| 5 | Разрешимость CE до порядка **ε⁴** | **формально да** |
| 6 | Оценка остатка **R_4 = p^ε − p^(0) − ε²p₁ − ε⁴p₂** на **{r≥δ}** | **открыто** |
| 7 | Внутренний слой **r ~ O(ε)** | **открыто** |
| 8 | Сходимость / асимптотичность ряда | **открыто** |

---

### 17.7. Итоговая формулировка

**Хасминский (p^(0), f_R, q):**

- имеет **теоретическое обоснование** в рамках теории усреднения SDE;
- типичная оценка: **O(ε²)** для маргинальной и условной плотности;
- **E[r²] = ν/(2αA)** — проверяемый след теоремы.

**Чепмен–Энског (p₁, p₂):**

- **формальная** асимптотическая иерархия; явные **p₁, p₂** **согласованы** с уравнением на порядках **ε², ε⁴**;
- **сходимость ряда не утверждается**;
- ожидаемая точность усечения на **{r ≥ δ}**: **O(ε⁴)** или **O(ε⁶)** — **эвристика**, не теорема.

**KH + CE вместе:**

- **p^(0)** — наиболее обоснованная часть;
- **−ε²κp₀/r + ε⁴p₂** — **физически и формально согласованные** поправки, но **глобальная L¹-оценка** требует **дополнительного** анализа (слой у **r = 0**, остаток **R_4**).

**Литература (общая):** Khasminskii (1966); Freidlin–Wentzell, *Random Perturbations of Dynamical Systems*; Pavliotis–Stuart, *Multiscale Methods*; Bensoussan–Lions–Papanicolaou, *Asymptotic Analysis for Periodic Structures* (гомогенизация / CE).
