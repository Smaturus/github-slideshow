# Решения (ADR, кратко)

Неочевидные договорённости проекта. Обзор — в [README](../README.md), детали — в [architecture.md](architecture.md).

## Hero / первый экран

| Решение | Почему |
|---------|--------|
| Фон = `assets/Image 1.png` (мастер) | Утверждённый арт; не перекрашивать, не кропать намеренно |
| Раскладка = `assets/Image 2.png` | Только эталон позиций текста, nav и дат |
| В Pages — только `hero-bg*.{avif,webp,jpg}` | Мастер PNG не публикуем; responsive AVIF→WebP→JPEG |
| Годы на hero: 1834…2001 по Image 2 | Иллюстративная раскладка, не слоты GEDCOM |
| Пунктиры у 1834/1858 — HTML/CSS | В Image 1 линий нет |
| Header = 7 пунктов, без brand | О проекте … Контакты · Древо |

## Данные и сборка

| Решение | Почему |
|---------|--------|
| `data/skiba.ged` не в Git | Privacy: живые люди в экспорте |
| Сборка локальная, не в CI | GEDCOM нельзя отдавать в Actions |
| Архивные предки — код в `parse_gedcom.py` | Экспорт MyHeritage можно перезаливать; вставка на `@I155@` |
| YAML — только тексты | Факты считает генератор |

## Публикация

| Решение | Почему |
|---------|--------|
| Allowlist `gh-pages` | Не утекут скрипты, YAML, мастер-арт |
| `.nojekyll` | Отключить Jekyll на Pages |
| Коммитить `index.html` после `build_site.py` | CI сайт не собирает |
