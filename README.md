# Род Матюхиных и Скиба — семейный архив

**Live:** https://smaturus.github.io/github-slideshow/

Персональный генератор семейного архива: GEDCOM-экспорт MyHeritage → статический сайт с летописью рода, ономастикой, географией и SVG-древом прямых предков. Проект сочетает семейную задачу с инженерным подходом: приватность живых родственников, разделение данных и текстов, воспроизводимая сборка и автоматическая публикация.

---

## Возможности

- **Летопись** — четыре родовые линии, таймлайн поколений, блок «точка встречи» двух ветвей
- **Ономастика и география** — частые фамилии и места рода с пояснениями
- **SVG-древо** — прямые предки с пометками «подтверждено / гипотеза / нет данных»
- **Карта поиска** — приоритетные «белые пятна» в прямой линии
- **Редактируемые тексты** — заголовки и абзацы в `content/content.yaml` без правок Python

---

## Архитектура

```
data/skiba.ged          ──►  parse_gedcom.py  ──┐
  (локально, не в Git)                          ├──►  build_site.py  ──►  index.html
content/content.yaml    ────────────────────────┘         ▲
assets/site.css         ──────────────────────────────────┘
                                                          │
merge в master ──► GitHub Actions ──► gh-pages ──► GitHub Pages
                                      (только index.html,
                                       .nojekyll, assets/)
```

| Слой | Источник | Ответственность |
|------|----------|-----------------|
| **Данные** | `data/skiba.ged` | Имена, даты, связи, статистика |
| **Контент** | `content/content.yaml` | Заголовки, абзацы, подписи, легенда |
| **Генератор** | `scripts/build_site.py` | Сборка HTML, SVG-древо, фильтрация приватности |
| **Публикация** | `.github/workflows/pages.yml` | Деплой только статических файлов в `gh-pages` |

## Инженерные решения

**Privacy-by-design.** GEDCOM не хранится в репозитории (`.gitignore`). Для ныне живущих на сайте публикуются только имя и год рождения; точные даты, места и контакты отфильтровываются в `parse_gedcom.py`.

**Разделение фактов и текстов.** Факты из GEDCOM собираются в Python; абзацы в YAML — обычный текст без `{плейсхолдеров}`. Редактор контента не рискует сломать логику генератора.

**Валидация YAML.** `build_site.py` проверяет обязательные ключи и типы в `content/content.yaml` и падает с понятным сообщением, если структура нарушена.

**Безопасная публикация.** Workflow публикует в `gh-pages` только allowlist: `index.html`, `.nojekyll`, `assets/`. Скрипты, YAML и служебные файлы на live-сайт не попадают.

**Осознанный trade-off.** Сборка не выполняется в CI: GEDCOM содержит персональные данные и остаётся локально. Перед merge в `master` обновлённый `index.html` коммитится вручную после локальной пересборки.

## Технологии

- Python 3, PyYAML

- Статический HTML + инлайн-CSS + SVG

## Быстрый старт

```bash
# 1. Положите экспорт MyHeritage в data/skiba.ged (файл не коммитится)
mkdir -p data
cp /путь/к/экспорту.ged data/skiba.ged

# 2. Установите зависимости и соберите сайт
python3 -m pip install -r requirements.txt
python3 scripts/build_site.py

# 3. Локальный просмотр
python3 -m http.server 8080
# → http://localhost:8080
```

### Редактирование текстов

1. Правки в `content/content.yaml`
2. `python3 scripts/build_site.py`
3. Коммит `content/content.yaml` и `index.html` → merge в `master`

---

## Публикация

После merge в `master` workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) автоматически обновляет ветку `gh-pages`.

**Требования к репозиторию (один раз):**

- `Settings` → `Actions` → `General` → **Read and write permissions** для workflow
- Ветка `gh-pages` не должна блокировать force-push от GitHub Actions

## Структура репозитория

| Путь | Назначение |
|------|------------|
| `data/skiba.ged` | GEDCOM-экспорт, локально, в Git не попадает |
| `content/content.yaml` | Редактируемые тексты сайта |
| `scripts/parse_gedcom.py` | Парсер GEDCOM, модель персон, приватность |
| `scripts/build_site.py` | Генератор `index.html`, валидация YAML |
| `assets/site.css` | Стили |
| `index.html` | Собранный сайт (коммитится в `master`) |
| `requirements.txt` | Python-зависимости |
| `.github/workflows/pages.yml` | Автопубликация в `gh-pages` |

---

## Приватность

GEDCOM содержит точные даты, места и контакты **ныне живущих** людей. Файл **не хранится в репозитории**. Генератор автоматически ограничивает публикацию: для живых без даты смерти на сайте видны только имя и год рождения («р. 1971»).
